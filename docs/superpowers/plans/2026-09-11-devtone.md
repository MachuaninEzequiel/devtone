# DevTone v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a single-process Linux daemon `devtone` that plays light lofi, draws a 32-bar amp in TUI + notch, and maps pi / Claude Code / Codex CLI / OpenCode activity to music without reading source or prompts.

**Architecture:** Cargo workspace, one process, `ArcSwap` snapshots (`StateFrame`, `MusicParams`, `SpectrumSnap`) plus a bounded `Command` channel. Audio callback never locks or allocates. Sensors tail jsonl / OpenCode sqlite; CLI identity is `--agent` > focused TTY/window > last `TokenDelta` < 90 s.

**Tech Stack:** Rust 2021, cpal, ratatui/crossterm, winit/softbuffer, microfft, notify, rusqlite (bundled), clap, serde_json, toml, arc_swap, crossbeam-channel.

**Spec:** `docs/superpowers/specs/2026-09-11-devtone-design.md`

## Global Constraints

- Edition 2021, workspace resolver 2, binary name `devtone`.
- Default features: `tui` + `notch`. `--no-default-features --features tui` must still build.
- No `Mutex` and no alloc in the audio callback. No `rustfft`. No Electron/wgpu. No reading prompts or source.
- Agents in v1: `Pi`, `ClaudeCode`, `CodexCli`, `OpenCode` only.
- Arbitration: `--agent` > focus-if-CLI > last event < 90 s > `None`.
- Palette and peak-hold 0.86 as in the spec. BPM mostly 72–84.
- Platform of record: Linux KDE Plasma 6 Wayland. macOS/Windows are compile stubs.
- Track `Cargo.lock` (application). Do not gitignore it.
- TDD: failing test first, watch it fail, then minimal code. Commit after each task.
